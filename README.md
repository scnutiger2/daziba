# 打字练习（daziya）

一个零依赖的在线指法打字练习页面：逐字符高亮、虚拟键盘指法提示、实时速度/准确率统计，交互方式参照常见在线打字课程的打字效果。

## 运行方式

方式一：直接双击 `index.html` 用浏览器打开（纯静态，无需构建）。

方式二：起一个本地静态服务（便于手机同局域网访问）：

```bash
cd D:/workspace/daziya
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 功能

- **逐字高亮**：待输入字符蓝色脉冲光环；正确输入浅绿并弹一下；打错时该字符立即标红，光标照常前进到下一个位置，按 Backspace 可退回重打，回退处显示黄色提示。最后一个字符打错时不会立刻结算，而是停在文末提示退格修改，改对后才弹出结果面板。
- **空格位标记**：空格用一条淡色短下划线表示“这里要按空格”，不用圆点，避免被误认成句号或小数点；轮到空格时下划线跟随主色高亮。
- **准确率口径**：只在整篇打完后按最终文本结算——打错后回退重打的不计入，只有留在文末没改的错误才算不准确。
- **虚拟键盘**：完整 5 行键位（50px 键帽、6px 圆角），键盘底座带内阴影与描边，键帽有两层投影呈轻微立体；鼠标悬停时键帽上浮 2px、描边与文字转主色并加投影，按下缩回并显示内阴影；当前目标键以主色底白字高亮，按错的键短暂标红（约 0.45 秒后自动褪回常态）。
- **长按防连击**：按住一个键不松手只算一次输入，系统自动重复的按键事件会被丢弃（退格同样只退一格）；松手后才能再次输入同一个键，符合正常打字节奏。
- **指法提示**：显示"左手 / 食指 / 输入按键 F"这类提示，可一键关闭；特殊符号会同时提示对应的 Shift 组合（如 `#` 显示"Shift + 3"），并按基础键给出左右手与手指。每关的练习说明（如"先慢一点，看着指法提示把每个键按准"）就排在指法提示下方，换关时同步更新。
- **按键音**：每敲一个字符都有一声清晰短促的机械感敲击声（高频瞬态 + 短音体，峰值约 -6dB，听得清又不刺耳），答对音调略高、按错是柔和低音、退格也有一声轻响；声音由 Web Audio 在本地实时合成，不依赖音频文件，点顶部「按键音」可开关，开关状态会记住。
- **实时统计**：速度（字/分钟）、表现星星、连对、用时；首次击键才开始计时，暂停期间不计时。
- **儿童激励**：不显示会随出错下跌的准确率百分比，改为 5 颗"表现星星"——按稳妥准确率（分母取 30 与本关字符数中的较小者，既避免第一下就满星，也保证短关卡能拿满星）分档点亮，每 20 个百分点一颗星：**≥80% 即满 5 星**，60%-79%→4 星，40%-59%→3 星，20%-39%→2 星，20% 以下→1 星；**只升不降**，按错时星星停在原处不会变暗。另设"连对"计数与一句鼓励语（按错时给温柔提示，2 秒内回到鼓励语）。
- **进度条**：键盘上方的 4px 绿色进度条，按已输入字符比例推进。
- **135 个关卡**：编号与站内课程一致，分 7 章——基准键（1-18）、上排字母（19-43）、下排字母（44-64）、特殊符号（65-76）、手指旅行（77-94）、左右手练习（95-106）、拼音练习（107-135）；点「选择关卡」打开分章面板按编号选关，学习关只练新键，练习/回顾/游戏关按节奏混练。Tab 与 Shift 两个特殊键关卡已支持单独按键判定，拼音关卡全部用小写字母输入（ü 用 v 代替）。
- **自定义文本**：可粘贴任意英文 / 数字 / 符号文本作为临时关卡。
- **完成统计**：打完当前文本弹出结果面板，以星星为主，附最长连对、本次准确率、用时与本关历史最好星星（按关卡分别保存在本地）；可"再练一次"或"下一关"。完成时会在整页范围内撒花（44 片彩纸从视口顶端铺满屏幕下落，盖在弹层之上但不挡点击）、星星从第一颗起依次弹出、徽章弹跳，并播放一段四音上行完成音效（受「按键音」开关控制，关掉后只有动画没有声音）。
- **鼓励提示条**：鼓励语做成文本区下方的胶囊提示条（20px 粗体、主色淡底 + 描边 + 投影），文案变化时会轻轻弹一下；按错时的温柔提醒会换成低调配色，避免像警告。
- **配色预设**：点顶部「配色」可切换 5 套预设——雾紫奶油、樱花粉、薄荷青、蜜桃暖阳、莓果紫，每套都带浅色与深色变体（`data-palette` 管色相，`data-theme` 管明暗，两个维度可自由组合）；切换即时生效，配色与深浅都会记在本地，下次打开保持上次选择。
- **主题切换**：浅色 / 深色。深色为对应色相的暗色版（底色约 `#12201d`–`#221a22`、高亮取浅色主色的提亮版）；语义色在各套配色下都固定：正确薄荷绿、错误红、退格琥珀，保证"绿=对、红=错"的直觉一致。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 任意字母键 | 开始计时并输入字符 |
| Backspace | 回退一格，重新输入 |
| 暂停按钮 / 空格 | 暂停或继续（暂停时按空格继续） |
| 选择关卡 | 打开分章关卡面板，点任意关卡切换并重置进度 |
| Tab / Shift | 在对应关卡中直接按这两个键推进练习 |
| 自定义文本 | 打开输入弹层，粘贴任意 ASCII 文本 |
